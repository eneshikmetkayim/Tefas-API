TEFAS Pure-HTTP API İstemcisi

Türkiye Elektronik Fon Alım Satım Platformu (TEFAS) verilerine tarayıcı otomasyonu (Playwright/Chromium) olmadan, doğrudan resmi JSON uç noktalarına POST istekleriyle erişen Python, TypeScript / JavaScript, Go, C# / .NET, Java ve Rust kütüphanelerinin eksiksiz teknik referansı.

Mimari ve Dayanıklılık Mekanizmaları

Sayfa HTML'ine yapılan istekler WAF'a takıldığı için tüm istemciler doğrudan https://www.tefas.gov.tr/api/... JSON uç noktalarına standart tarayıcı başlıklarıyla POST gönderir.

Kurulum ve İstemci Yapılandırması

Üst menüden veya sekmelerden istediğiniz dili seçtiğinizde sayfadaki tüm örnekler otomatik senkronize olur.

Desteklenen Fon Piyasaları (FundType)

Tüm listeleme, sıralama, büyüklük ve dağılım uç noktaları aşağıdaki 5 TEFAS piyasasını destekler.

Tüm Dillerde 19 Metot Karşılaştırma Matrisi

Her satır ilgili metot kartına doğrudan bağlantı verir.

7 Ana Metod (Tüm Dillerde)

Günlük fon listeleme, tekil detay, 28 günlük otomatik parçalı fiyat geçmişi, 22 sınıflı varlık dağılımı, sıralama, piyasa özeti ve istemci içi arama.

12 Araştırılmış Ek ve Referans Endpoint

Tekil özet/kategori sıralaması, ISIN ve işlem profili, 1–60 aylık tek istek seri, büyüklük değişimi, yönetim ücretleri, kurucular, şemsiye fonlar ve duyurular.

Ham HTTP Uç Noktaları ve curl Referansı

SDK kullanmadan doğrudan HTTP çağrısı yapmak veya hata ayıklamak için tüm 13 doğrulanmış POST endpoint şeması.

Veri Modelleri, Python sync_* ve Hata Yönetimi

Varlık sınıfları eşlemesi, her dilin hata modeli, Python senkron arayüzü ve test komutları.
