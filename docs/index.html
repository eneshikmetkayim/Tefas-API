Tarayıcı CORS Kısıtlaması ve 1 Dakikada Canlı Proxy Kurulumu (Python / Cloudflare Worker) İsteğe Bağlı

TEFAS sunucusu (www.tefas.gov.tr) Access-Control-Allow-Origin başlığı göndermediği için GitHub Pages gibi farklı bir alandan doğrudan tarayıcı fetch() çağrısı CORS engeline takılır. Gerçek canlı veri denemek için aşağıdaki iki sıfır-maliyetli yoldan birini kullanabilirsiniz:

1. Yerel Python Relay (Sıfır Bağımlılık)

Docs sitesini ve aynı-köken (same-origin) TEFAS proxy'sini http://127.0.0.1:8787 adresinde başlatır.

2. Ücretsiz Cloudflare Worker (Her Yerden Canlı)

Tek dosya Worker oluşturup URL'yi yukarıdaki Proxy alanına yapıştırırsanız GitHub Pages üzerinden doğrudan canlı veri akar.
